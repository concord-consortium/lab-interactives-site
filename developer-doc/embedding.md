Lab interactives can be embedded in parent pages and then postMessage used to modify, observer, and change the interactive. 

There are two general examples of using this feature.

# Lab Examples
https://concord-consortium.github.io/lab-examples/
https://github.com/concord-consortium/lab-examples

This site and repository show how to use many of the APIs available through postMessage.

# React Lab
https://github.com/concord-consortium/react-lab
https://github.com/concord-consortium/react-lab-examples
https://concord-consortium.github.io/react-lab-examples/

This provides a React component that can be used to render an embedded Lab interactive and then work with via these same postMessage APIs.
